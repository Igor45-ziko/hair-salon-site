# Материалы проекта

## Оригинальные изображения

Все интерьерные изображения созданы с помощью генерации изображений специально для вымышленной гостиницы «ГОРОДСКОЙ ДОМ». Фотографии реальных гостиниц, их сайты и фирменный стиль не использованы. Изображения иллюстрируют концепцию, а не существующий объект.

- `public/images/room-hero.webp`: светлая спальня с двуспальной кроватью, деревянной мебелью и зелёными подушками.
- `public/images/rooms-reception.webp`: четыре согласованные по стилю сцены — Стандарт, Комфорт, Семейный и ресепшен.
- `public/images/hotel-details.webp`: ванная, вымышленный фасад, простой завтрак и гостиная.

Изображения оптимизированы в WebP. Два контактных листа разделяются на отдельные фотографии средствами CSS в `Photo.tsx`; оригинальные сцены не искажаются и не требуют внешних запросов. В галерее открывается только выбранная сцена, а не весь контактный лист.

Логотип, favicon и декоративная SVG-карта также созданы для этого проекта. Карта не отображает реальный маршрут и не использует картографический API.

## Шрифт Onest

Шрифт устанавливается через `@fontsource-variable/onest` и обслуживается локально. Используется по лицензии SIL Open Font License 1.1; текст находится в `public/Onest-LICENSE.txt` и в npm-пакете.

## Иконки Lucide

Иконки подключены через `lucide-react`, лицензия ISC. Лицензия включена в npm-пакет. В production-сборку попадают используемые иконки, сторонний сервис не требуется.
