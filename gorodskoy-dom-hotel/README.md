# ГОРОДСКОЙ ДОМ

Самостоятельный учебный сайт небольшой городской гостиницы в Москве — третий проект для портфолио веб-разработчика. Концепция: 20 номеров, средний ценовой сегмент, спокойный отдых без лишней суеты.

## После скачивания

Установите **Node.js 22.12 или новее** (рекомендуется **Node.js 24 LTS**). npm поставляется вместе с Node.js.

Распакуйте `gorodskoy-dom-hotel.zip`, откройте терминал рядом с папкой проекта и выполните:

```bash
cd gorodskoy-dom-hotel
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале. Остановить сервер можно сочетанием `Ctrl+C`.

Если скачан весь GitHub-репозиторий, сначала перейдите в его папку `gorodskoy-dom-hotel`. Этот проект не зависит от сайтов салона красоты и автосервиса: у него собственные исходники, зависимости и команды.

## Production

```bash
npm run build
```

Команда проверяет TypeScript и собирает сайт в `dist/`. Для локальной проверки готовой версии:

```bash
npm run preview
```

Содержимое `dist/` можно разместить на статическом хостинге. Настройка `base: './'` поддерживает публикацию в подкаталоге. Запускайте сайт через HTTP-сервер, а не двойным щелчком по HTML-файлу.

## Что реализовано

- Светлый адаптивный дизайн: молочный фон, натуральные древесные оттенки и зелёно-серый акцент.
- Первый экран, три категории номеров, удобства, рассказ об отеле, галерея из шести фотографий, расположение, отзывы, бронирование, FAQ, контакты и финальное приглашение.
- Мобильное меню, плавная навигация, hover-состояния и видимый фокус клавиатуры.
- Увеличение всех изображений галереи; переключение кнопками и стрелками клавиатуры; закрытие по Escape или клику вне окна; возврат фокуса на исходную фотографию.
- Выбор категории из карточек номеров без сброса уже введённых дат.
- Валидация имени, российского номера телефона, дат и вместимости номера. Заезд не может быть в прошлом, выезд должен быть позже заезда минимум на день. Семейный номер рассчитан на трёх гостей, остальные — на двух; дети включаются в число гостей.
- После корректного заполнения: **«Демонстрация завершена. Заявка не отправлена.»**
- Раскрывающиеся вопросы на нативном `details`, демонстрационные окна маршрута и звонка.
- Поддержка `prefers-reduced-motion` и доступных диалогов.

## Учебные данные и приватность

Гостиница, адрес, цены, отзывы, рейтинг, время в пути и контакты вымышлены. Никакой связи с реальными гостиницами нет. Все изображения оригинальные, сгенерированы специально для проекта и хранятся локально. Подробнее — [ASSETS.md](ASSETS.md).

Форма обрабатывается только в браузере. Нет серверной отправки, онлайн-оплаты, реального бронирования, проверки доступности номеров, аналитики, cookies или сохранения персональных данных в `localStorage` / `sessionStorage`. После успешной демонстрации введённые значения очищаются. Даты сравниваются с текущим днём в часовом поясе `Europe/Moscow`.

Кнопка «Позвонить» показывает демонстрационный номер и пояснение: реального вызова нет. Кнопка «Построить маршрут» открывает пояснение о вымышленном адресе. Email использует зарезервированный домен `.example`. Платных или внешних API карт нет.

Цены указаны за номер за ночь и служат примером. Завтрак оплачивается отдельно по концепции; реальные тарифы и платежи не реализованы.

## Стек и структура

React 19, TypeScript, Vite 7, CSS, Lucide, локальный шрифт Onest. Для тестирования — Playwright и axe-core.

```text
gorodskoy-dom-hotel/
├── public/
│   ├── images/             # Оригинальные локальные WebP
│   ├── favicon.svg
│   └── Onest-LICENSE.txt
├── src/
│   ├── components/
│   │   ├── BookingForm.tsx # Форма и проверка данных
│   │   ├── Gallery.tsx     # Галерея с увеличением
│   │   ├── Header.tsx      # Навигация и мобильное меню
│   │   ├── LocationMap.tsx # Декоративная SVG-схема
│   │   ├── Logo.tsx
│   │   ├── Modal.tsx       # Общий доступный диалог
│   │   └── Photo.tsx      # Локальные фотографии
│   ├── App.tsx             # Разделы страницы
│   ├── booking.ts          # Работа с датами
│   ├── data.ts             # Номера, цены, тексты, отзывы
│   ├── main.tsx
│   └── styles.css
├── tests/
├── index.html
├── package.json
├── package-lock.json
├── playwright.config.ts
├── tsconfig.json
└── vite.config.ts
```

Основные тексты и цены меняются в `src/data.ts`, оформление — в `src/styles.css`.

## Браузерные проверки

```bash
npx playwright install chromium
npm run build
npm test
```

На Linux, если не хватает системных библиотек, используйте официальный установщик: `npx playwright install --with-deps chromium`.

Для уже установленного Chromium можно указать путь:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

Тесты проверяют ширины **360, 390, 768, 1024, 1440, 1920 px**, загрузку изображений, отсутствие горизонтального переполнения, меню, FAQ, все фотографии галереи, формы и даты, вместимость, отсутствие отправки и сохранения данных, диалоги и навигацию. Дополнительно axe-core проверяет доступность на двух размерах, включая ошибки формы и открытую галерею. Автоматические проверки не заменяют полноценный ручной аудит доступности.

Скриншоты сохраняются в `test-results/`. Тесты самостоятельно запускают production-preview на порту 4174; перед запуском нужна сборка.
