# СВОЙ СРЕЗ

Адаптивный одностраничный сайт вымышленного московского салона волос. React, TypeScript и Vite. Все фотографии и шрифты загружаются локально; внешние сервисы для работы страницы не требуются.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный Vite, обычно http://localhost:5173. При работе в удалённой среде откройте порт 5173 через интерфейс предпросмотра вашей среды.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`. Предпросмотр сборки обычно доступен на http://localhost:4173. Для публикации разместите содержимое `dist/` на статическом хостинге в корне домена. Сам репозиторий автоматически ничего не публикует.

## Что работает

- Навигация по разделам и мобильное меню.
- Фильтры восьми работ и увеличенный просмотр с клавиатурным управлением.
- Запись из шапки, услуг, карточек мастеров, акции и финального блока.
- Простая форма: имя, телефон, услуга; проверка полей и демонстрационный результат.
- Диалоги с блокировкой фона, Escape и возвратом фокуса.
- Мобильная нижняя кнопка записи и поддержка уменьшенного движения.

Форма ничего не отправляет и не сохраняет. Для проверки используйте вымышленные данные, например `Анна` и `+7 (000) 000-00-00`. Контактные кнопки показывают короткое уведомление, не открывая реальные номера и аккаунты.

## Структура

- `src/main.tsx` — страница, компоненты, диалоги и интерактив.
- `src/styles.css` — визуальная система и адаптивные стили.
- `src/data.ts` — услуги, мастера, работы, отзывы, навигация.
- `src/validation.mjs` — проверка формы.
- `public/images/` — локальные изображения WebP.
- `public/favicon.svg` — иконка сайта.
- `tests/booking.test.mjs` — тесты правил формы.
- `ASSETS.md` — происхождение изображений и лицензии шрифтов.

## Будущее подключение реальной записи

Замените вымышленные контакты в `src/main.tsx`, подключите серверный обработчик формы с проверкой данных и защитой от спама, добавьте фактическую политику обработки персональных данных. Сообщение о демонстрации заменяйте только после подключения и проверки реальной отправки. Вымышленные отзывы и портреты нельзя выдавать за настоящих клиентов и сотрудников действующего бизнеса.
