# Изображения и другие материалы

## Оригинальные изображения

Все изображения созданы специально для учебного проекта «Мария Орлова — частный кондитер в Москве» инструментом генерации изображений OpenAI. Они изображают вымышленные торты и вымышленного человека. Это не фотографии заказов реального кондитера.

Фотографии с TOBIZ, Behance, Pinterest, сайта «Крем», концепта «СЛОЙ» и других реальных проектов не использовались. Сгенерированные PNG преобразованы в локальный WebP с качеством 86. Ни один файл не загружается с внешнего фотосервиса во время работы сайта.

| Файл в `public/images/` | Содержание                                                                                                                | Где используется                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `hero.webp`             | Сливочный торт с ягодами и пудровыми свечами, 1024 × 1536                                                                 | Главный экран, работа «Ягодное настроение», финальный CTA |
| `products.webp`         | Сетка 2 × 2: медовик, шоколад-вишня, фисташка-малина, бенто; 1536 × 1024                                                  | Бестселлеры и соответствующие работы                      |
| `works.webp`            | Сетка 2 × 2: торт с мишкой, лавандовый торт, свадебный торт, капкейки; 1536 × 1024                                        | Четыре дополнительных примера портфолио                   |
| `fillings.webp`         | Сетка 3 × 2: разрезы медовика, фисташки-малины, шоколада-вишни, красного бархата, сникерса, ягодного йогурта; 1536 × 1024 | Шесть начинок                                             |
| `portrait.webp`         | Оригинальный портрет вымышленного мастера в домашней кухне, 1024 × 1536                                                   | Блок «Обо мне»                                            |

Компонент `Photo` показывает нужную ячейку составного изображения с помощью CSS-позиционирования. `cell` нумеруется слева направо, сверху вниз с нуля. Для четырёх кадров контейнер сохраняет пропорцию 3:2; для разрезов используется квадрат. Изображения имеют заданные размеры и контейнеры с `aspect-ratio`. Hero загружается сразу, изображения ниже первого экрана — лениво.

## Шрифты

- **Manrope Variable** — основной текст, npm-пакет `@fontsource-variable/manrope`. Лицензия: [public/Manrope-LICENSE.txt](public/Manrope-LICENSE.txt).
- **Playfair Display Variable**, прямое и курсивное начертания — крупные заголовки и акценты, npm-пакет `@fontsource-variable/playfair-display`. Лицензия: [public/Playfair-Display-LICENSE.txt](public/Playfair-Display-LICENSE.txt).

Оба шрифта распространяются по SIL Open Font License 1.1, поддерживают кириллицу и включаются Vite в локальную сборку. Google Fonts API в браузере не используется.

## Иконки и оформление

- Иконки [Lucide](https://lucide.dev/) подключены из локального npm-пакета `lucide-react`, лицензия ISC входит в пакет.
- SVG-знак торта, favicon и рисунок торта в FAQ созданы для проекта.
- Тексты, вымышленные отзывы, названия работ, композиция и оформление разработаны для этой концепции. Они не воспроизводят уникальные материалы сайтов-референсов.
- Декоративных внешних карт, реальных аккаунтов мессенджеров и платных API нет.
