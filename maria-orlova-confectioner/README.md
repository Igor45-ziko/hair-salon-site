# Мария Орлова — частный кондитер в Москве

Пятый самостоятельный учебный проект для портфолио веб-разработчика: современный одностраничный сайт частного кондитера. Это небольшая домашняя мастерская с тортами на заказ, бенто и десертными наборами.

**Учебный проект для портфолио. Имя кондитера, фотографии, цены, отзывы и контакты вымышлены. Формы работают только в демонстрационном режиме.**

## Технологии

React 19, TypeScript, Vite, собственный CSS, иконки Lucide. Manrope и Playfair Display подключены локально через Fontsource. Браузерные тесты — Playwright и axe-core. Внешних API, аналитики, платежей, CRM и сервисов отправки данных нет.

## Установка и запуск

Рекомендуется **Node.js 24 LTS** и npm. Минимальная версия Node.js — 22.12. Версия для nvm указана в `.nvmrc`.

На Windows распакуйте ZIP, откройте PowerShell или терминал в папке, содержащей проект, и выполните:

```bash
cd maria-orlova-confectioner
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Для установки пакетов нужен интернет. Во время работы страницы изображения, шрифты и скрипты загружаются с того же сервера, без внешних hotlink-ссылок.

## Production-сборка

```bash
npm run build
npm run preview
```

Сборка сначала проверяет TypeScript, затем создаёт `dist/`. Настроен относительный `base: './'`, поэтому файлы можно разместить на статическом хостинге в подпапке. Запускайте сайт через сервер, а не двойным щелчком по HTML через `file://`.

GitHub Pages в рамках этого проекта не настроен. Существующий Pages workflow общего репозитория не изменён.

## Реализованные функции

- Главный экран с ценовым ориентиром, условиями заказа и оригинальной фотографией торта.
- Четыре бестселлера с выбором торта и автоматическим заполнением повода и начинки в форме.
- Шесть поводов для заказа, переключающих фильтр портфолио.
- Девять работ и пять фильтров. Lightbox с кнопками, стрелками клавиатуры, Escape и возвратом фокуса. Переключение фотографий остаётся в выбранной категории.
- Шесть начинок с изображениями разрезов и подстановкой в форму; помощь с выбором.
- Преимущества, история вымышленного мастера, четыре этапа заказа, четыре вымышленных отзыва.
- Форма расчёта, раскрывающийся FAQ, информация об аллергенах, контакты и финальный CTA.
- Демо-кнопки Telegram и WhatsApp открывают пояснение, не ведут на реальные аккаунты и не отправляют сообщения.
- Адаптивное мобильное меню. Закреплённая мобильная кнопка скрывается, когда виден блок формы.
- Семантическая разметка, подписи полей и изображений, видимый фокус, управление с клавиатуры, лёгкое появление блоков. При `prefers-reduced-motion` анимации и плавная прокрутка отключаются.

## Форма и локальный выбор файла

Обязательны имя, телефон, повод, дата, количество гостей или примерный вес и начинка. Комментарий и пример оформления необязательны.

- Имя: минимум 2 символа.
- Телефон: 11 цифр с начальной 7 или 8; допустимы пробелы, скобки и дефисы.
- Дата: не раньше чем через 3 календарных дня относительно даты в Москве.
- Гости/вес: положительное число до 1000, например `10 гостей`, `2 кг` или `2,5 кг`.
- Файл: непустое изображение JPG, PNG или WebP до 10 МБ. Проверяются заявленный MIME-тип, расширение и размер. Это клиентская проверка демонстрации, серверной загрузки нет.

При выборе файла показывается только его имя. Содержимое не считывается и никуда не отправляется. Файл можно убрать. Выбор торта не стирает уже введённые имя, дату, комментарий и вложение. После успешной демонстрации форма очищается, включая файл, и показывает:

> Спасибо! Это демонстрационная форма учебного проекта — заявка никуда не отправлена.

Сайт не выполняет `fetch`, XHR, отправку формы или запись персональных данных в cookies, localStorage и sessionStorage. Ввод существует только в состоянии страницы и элементах формы до очистки или закрытия вкладки. Сайт не принимает реальные заказы.

## Тесты

Один раз установите Chromium для Playwright:

```bash
npx playwright install chromium
```

Затем:

```bash
npm run build
npm test
```

Playwright автоматически запускает production preview на свободном порту **4177**. Если Chromium уже установлен, можно использовать его напрямую.

Linux/macOS:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

PowerShell, если нужно явно указать установленный браузер:

```powershell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm test
```

24 автоматических теста проверяют:

- ширины **360, 390, 768, 1024, 1440, 1920 px**, загрузку локальных изображений, отсутствие горизонтального переполнения, lightbox и FAQ на каждой ширине;
- мобильное меню, замыкание фокуса, Escape, переходы и закрытие при расширении окна;
- фильтры, карточки поводов, все девять фотографий и клавиатурное управление галереей;
- выбор бестселлера и начинки с сохранением других полей;
- обязательные поля, ошибочный телефон, дату и количество гостей;
- локальный выбор, отображение и удаление файла; неподходящий формат, пустой и слишком большой файл;
- успешную демонстрацию без отправки данных, отсутствие записей в хранилища и полную очистку формы;
- FAQ, демо-мессенджеры, внутренние ссылки и режим уменьшенного движения;
- автоматическую доступность axe при 390 и 1440 px, включая ошибки формы и открытый lightbox.

Дополнительно проведён визуальный просмотр в Chromium. Тесты не заменяют проверку всех возможных браузеров и ассистивных технологий.

## ZIP и репозиторий

Проект находится в `maria-orlova-confectioner/`, ветка — `maria-orlova-confectioner`.

Архив в общем репозитории: `downloads/maria-orlova-confectioner.zip`. Он содержит одну папку проекта со всеми исходниками, изображениями, тестами и `package-lock.json`. В ZIP не включаются `node_modules`, `dist`, `.git`, `test-results`, `playwright-report`, `coverage` и временные файлы.

Архив проверяется распаковкой в чистую папку, отдельными `npm ci`, `npm run build` и `npm test`.
