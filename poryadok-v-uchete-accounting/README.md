# ПОРЯДОК В УЧЁТЕ

Самостоятельный учебный сайт небольшого бухгалтерского бюро для портфолио веб-разработчика. React 19 + TypeScript + Vite, локальный Inter через Fontsource, иконки Lucide, оригинальные локальные изображения WebP.

**Компания, специалисты, опыт, показатели, цены, отзывы и контакты вымышлены. Формы и калькулятор работают только в демонстрационном режиме.** Сайт не оказывает бухгалтерские услуги, не отправляет обращения и не сохраняет введённые данные. Backend, аналитика, CRM и внешние сервисы не подключены. Telegram открывает информационное демо-окно.

## Возможности

- Все разделы лендинга: услуги, доверие, три тарифа, калькулятор, этапы работы, команда, показатели, отзывы, FAQ, консультация и контакты.
- Адаптивное меню, плавные якоря, клавиатурная навигация, управление фокусом в диалогах, лёгкие reveal-анимации и поддержка `prefers-reduced-motion`.
- Выбор любой из шести услуг или тарифа переносится в форму. Калькулятор переносит сумму и снимок параметров, сохраняя введённые имя и комментарий. Ручное изменение услуги или формы бизнеса убирает устаревшую пометку расчёта.
- Валидация обязательных полей, российского телефона из 11 цифр с 7 или 8, локальное сообщение об успехе и очистка полей.
- Локальные изображения и шрифты: после сборки сайт не обращается к CDN и не использует хотлинки.

## Запуск

Нужен Node.js **24 LTS** (версия указана в `.nvmrc`; минимальная поддерживаемая — 22.12) и npm. Проект независим от соседних каталогов репозитория. Распакуйте ZIP, откройте терминал в папке проекта:

```sh
cd poryadok-v-uchete-accounting
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite в терминале. В Windows команды выполняются в PowerShell или терминале VS Code. `npm ci` использует включённый `package-lock.json`.

```sh
npm run build
npm run preview
```

Сборка включает строгую проверку TypeScript и создаёт `dist/`. Её нужно открывать через HTTP-сервер, а не двойным щелчком по HTML. Относительный `base: './'` позволяет размещать сборку в подкаталоге. GitHub Pages для проекта не настроен; существующие workflow репозитория не изменены.

## Тесты

Playwright запускает production preview на порту **4179**; порт должен быть свободен. Сначала установите браузер:

```sh
npx playwright install chromium
npm run build
npm test
```

На Linux для установки системных библиотек при необходимости используется `npx playwright install --with-deps chromium` (требует соответствующих прав). Если Chromium уже установлен, можно указать путь вместо загрузки браузера:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

В PowerShell: `$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH = 'C:\path\to\chrome.exe'`, затем `npm test`. Переменная необязательна при использовании установленного Playwright браузера.

25 браузерных тестов проверяют ширины **360, 390, 768, 1024, 1440, 1920 px**, отсутствие горизонтального переполнения, загрузку локальных изображений, калькулятор и его сброс, перенос услуг/тарифов/расчёта, валидацию и отсутствие отправки данных, мобильное меню, FAQ, диалог Telegram, якоря, reduced motion и автоматические проверки axe для WCAG A/AA. Автоматическая проверка доступности не заменяет полный ручной аудит.

| Параметр | Добавка, ₽/месяц |
| --- | ---: |
| База ИП / ООО | 4 900 / 8 900 |
| Сотрудников нет / 1–5 / больше 5 | 0 / 2 500 / 6 000 |

| Маркетплейсы | 3 500 |

Это учебная арифметическая модель, а не реальный расчёт бухгалтерских услуг. Тарифы — отдельные примеры пакетов; калькулятор показывает независимый ориентир.

## Структура

- `src/App.tsx`, `src/data.ts` — секции и содержимое;
- `src/components/` — меню, диалоги, калькулятор, форма и иллюстрации;
- `src/calculation.ts`, `src/validation.ts` — расчёт и проверка формы;
- `src/styles.css` — дизайн, адаптивность и анимации;
- `public/` — локальные изображения, favicon и лицензия Inter;
- `tests/site.spec.ts` — браузерные проверки;
- `ASSETS.md` — происхождение визуальных материалов.

## Архив и проверка

В репозитории архив находится по пути `downloads/poryadok-v-uchete-accounting.zip`, в отдельной ветке `poryadok-v-uchete-accounting`. Он содержит только папку этого самостоятельного проекта. В архив не включены `node_modules`, `dist`, `.git`, `test-results`, `playwright-report`, `coverage` и временные файлы.

Для независимой проверки распакуйте архив в пустую папку, перейдите в проект и выполните `npm ci`, `npm run build`, `npm test` с установленным Chromium по инструкции выше.
