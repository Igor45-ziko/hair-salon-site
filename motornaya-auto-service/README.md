# МОТОРНАЯ — автосервис полного цикла

Самостоятельный учебный проект для портфолио веб-разработчика. Одностраничный сайт вымышленного московского автосервиса: «Ремонт без лишних работ и сюрпризов в счёте».

## Быстрый запуск

Понадобится **Node.js 22.12+** (рекомендуется Node.js 24 LTS) и npm.
Распакуйте `motornaya-auto-service.zip`, откройте терминал в папке проекта:

```bash
cd motornaya-auto-service
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Остановить сервер: `Ctrl+C`.
`npm install` также поддерживается, но `npm ci` устанавливает точные версии из `package-lock.json`.

Если скачан весь репозиторий `hair-salon-site`, сначала перейдите в его вложенную папку `motornaya-auto-service`. Корень репозитория содержит отдельный первый проект — сайт салона красоты.

## Production-сборка

```bash
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт готовый сайт в `dist/`. `preview` запускает локальный сервер для проверки сборки. Для публикации скопируйте содержимое `dist/` на статический хостинг. Относительный `base: './'` позволяет размещать сайт в подкаталоге. Открывать `index.html` двойным щелчком не нужно: используйте HTTP-сервер.

## Что реализовано

- Оригинальный графитовый стиль, тёплые светлые секции, оранжевый акцент и локальные изображения.
- Фиксированная навигация, мобильное меню с управлением с клавиатуры и плавные переходы.
- Первый экран, 8 услуг, подход сервиса, цены, 5 этапов ремонта, 3 мастера, гарантия, 3 отзыва, FAQ, контакты, форма и подвал.
- Карточки услуг и строки прайса подставляют услугу в форму записи.
- Проверка имени и российского номера телефона, сообщения об ошибках и успешная демонстрация.
- FAQ на нативном `details`, диалог со схемой проезда и закрытие по Escape.
- Адаптивность для 360, 390, 768, 1024, 1440 и 1920 px; учтён `prefers-reduced-motion`.
- Фокус клавиатуры, ссылка пропуска навигации, подписи полей, локальный шрифт Manrope с кириллицей.

## Данные и изображения

Автосервис, сотрудники, отзывы, рейтинг, адрес, цены, гарантии и контакты **вымышлены**. Иллюстрации созданы с помощью генерации изображений специально для проекта; лица не представляют реальных сотрудников. Подробности — в [ASSETS.md](ASSETS.md).

Форма не вызывает `fetch`, не отправляет сообщения, не использует сервер, cookies, `localStorage` или `sessionStorage`. Значения используются только для проверки в браузере и очищаются после демонстрации. После заполнения показано: **«Демонстрация завершена. Заявка не отправлена.»**

Телефон намеренно не является рабочим номером, email использует зарезервированный домен `.example`. Кнопка «Построить маршрут» показывает демонстрационную схему: реального адреса и интеграции с картографическими сервисами нет. Аналитика и внешние запросы при работе сайта отсутствуют; все изображения и шрифты загружаются с самого сайта.

## Стек и структура

React 19 · TypeScript · Vite 7 · Lucide · CSS · Playwright · axe-core.

```text
motornaya-auto-service/
├── public/
│   ├── images/           # Оригинальные изображения WebP
│   ├── favicon.svg
│   └── Manrope-LICENSE.txt
├── src/
│   ├── components/       # Меню, логотип, форма, схема проезда
│   ├── App.tsx           # Разделы страницы
│   ├── data.ts           # Услуги, цены, команда, отзывы и FAQ
│   ├── main.tsx          # Точка входа
│   └── styles.css        # Визуальная система и адаптивность
├── tests/                # Функциональные проверки и доступность
├── index.html
├── package.json
├── package-lock.json
├── playwright.config.ts
├── tsconfig.json
└── vite.config.ts
```

Тексты и цены редактируются в `src/data.ts`, основные разделы — в `src/App.tsx`, оформление — в `src/styles.css`.

## Проверки

```bash
npx playwright install chromium
npm run build
npm test
```

Для Linux при необходимости установите системные зависимости браузера через `npx playwright install --with-deps chromium`.
Если Chromium уже установлен, можно указать его путь, например:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

Тесты запускают production-preview, проверяют шесть ширин, отсутствие горизонтального переполнения, изображения, навигацию, FAQ, выбор услуги, валидацию, отсутствие отправки формы, очистку значений и диалог маршрута. Отдельно выполняется автоматическая проверка axe-core на мобильном и настольном экране, включая открытый диалог. Автоматическая проверка не заменяет полную ручную оценку доступности.

Скриншоты проверенных размеров сохраняются в `test-results/`; эта папка не включается в Git и ZIP. В архив также не включены `node_modules`, `dist` и служебные файлы Git.

## Независимость от первого проекта

У проекта собственные зависимости, исходники, изображения и команды сборки. Он не импортирует файлы сайта салона красоты. Существующий workflow GitHub Pages в корне репозитория относится к первому проекту и автоматически «МОТОРНУЮ» не публикует.
