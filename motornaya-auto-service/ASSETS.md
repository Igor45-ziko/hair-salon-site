# Изображения, шрифты и иконки

## Оригинальные изображения

`public/images/workshop.webp` и `public/images/team.webp` созданы с помощью генерации изображений специально для учебной концепции «МОТОРНАЯ». Исходные сайты автосервисов, их фотографии, тексты и фирменный стиль не использовались.

- `workshop.webp`: автомобиль в чистом современном сервисном боксе с графитовыми подъёмниками и оранжевыми деталями интерьера.
- `team.webp`: три отдельных вымышленных специалиста в единой мастерской. Один локальный триптих отображается как три портрета средствами CSS; браузер скачивает файл только один раз.

Изображения преобразованы в WebP для быстрой загрузки. Это иллюстрации вымышленного бизнеса, а не документальные фотографии. Логотип «МОТОРНАЯ», favicon и декоративная карта созданы для этого проекта в SVG/CSS. Реальные товарные знаки не используются для обозначения связи с каким-либо производителем.

## Manrope

Шрифт устанавливается пакетом `@fontsource-variable/manrope`, обслуживается локально и собирается Vite. Лицензия SIL Open Font License 1.1 скопирована в `public/Manrope-LICENSE.txt`. Исходная лицензия также находится в пакете зависимости.

## Lucide

Иконки предоставлены пакетом `lucide-react` по лицензии ISC. Лицензия включена в npm-пакет. Используются только импортированные иконки; внешние сервисы не требуются.
