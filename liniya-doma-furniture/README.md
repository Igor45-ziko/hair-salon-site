# ЛИНИЯ ДОМА

Самостоятельный учебный сайт небольшой московской мастерской мебели на заказ. Четвёртый проект для портфолио веб-разработчика. React 19, TypeScript и Vite; собственные стили без UI-фреймворка.

**Компания, проекты, цены, показатели, отзывы и контакты вымышлены. Формы демонстрационные.**

## Запуск

Рекомендуется Node.js 24 LTS (версия указана в `.nvmrc`) и npm. Минимальная версия Node.js — 22.12.

Распакуйте ZIP и выполните из папки, содержащей проект:

```bash
cd liniya-doma-furniture
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Установка зависимостей требует подключения к интернету. Фотографии, иконки и шрифты при работе сайта загружаются локально.

## Production

```bash
npm run build
npm run preview
```

Сборка включает проверку типов TypeScript. Готовые файлы находятся в `dist/`. Их можно разместить на статическом хостинге. В Vite настроен относительный `base: './'`, поэтому сайт может работать в подпапке. Открывать `index.html` двойным щелчком через `file://` не нужно: используйте сервер Vite или статический хостинг.

## Что реализовано

- Адаптивная страница из 15 разделов, навигация по якорям, мобильное меню, закреплённая мобильная кнопка расчёта, которая скрывается при появлении блока формы.
- Пять направлений мебели. Кнопки карточек и строки цен подставляют выбранное направление в форму, сохраняя уже введённое имя и комментарий.
- Семь вымышленных проектов, пять фильтров, увеличенные изображения с размерами, материалами и ценой. Переключение стрелками на экране и клавиатуре; Escape закрывает окно и возвращает фокус.
- Материалы, интерактивные образцы оттенков, этапы заказа, мастерская, отзывы, раскрывающийся FAQ и декоративная схема адреса.
- Формы замера и обратного звонка с проверкой имени, российского номера телефона и выбора мебели. Ошибки связаны с полями, фокус переходит к первому неверному полю.
- После успешного заполнения появляется «Демонстрация завершена. Заявка не отправлена.». Поля очищаются. Данные не отправляются, не записываются в localStorage, sessionStorage или cookies. Обратный звонок сбрасывается при закрытии окна.
- Оригинальные изображения в WebP, локальный Golos Text, SVG-логотип и иконки Lucide. Источники и лицензии описаны в [ASSETS.md](ASSETS.md).
- Семантическая разметка, видимый фокус, ссылка пропуска навигации, нативные диалоговые окна и поддержка `prefers-reduced-motion`.

Это не интернет-магазин: сервер заявок, аналитика, платежи, аккаунты и внешние карты не подключены. Контакты показаны как вымышленные, email использует зарезервированную зону `.example`.

## Браузерные проверки

```bash
npx playwright install chromium
npm run build
npm test
```

Если Chromium уже установлен, можно указать путь к нему вместо загрузки браузера (пример для Linux):

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

Playwright автоматически запускает production preview на порту 4175, который должен быть свободен. На Linux при необходимости установите системные зависимости командой `npx playwright install --with-deps chromium`.

19 тестов охватывают размеры **360, 390, 768, 1024, 1440 и 1920 px**, отсутствие горизонтального переполнения, загрузку локальных изображений, мобильное меню, фильтры, все семь фотографий, управление галереей с клавиатуры, подстановку мебели, FAQ, оттенки, обязательные поля, отсутствие запросов и хранилищ при работе форм, сброс данных, внутренние ссылки и проверки доступности axe при ширинах 390 и 1440 px. Автоматические проверки дополнены визуальным просмотром в Chromium.

## Структура

```text
src/

  data.ts              — мебель, проекты, материалы и тексты

public/

```

## Архив и независимость

Ветка репозитория: `liniya-doma-furniture`.

Архив: `downloads/liniya-doma-furniture.zip` в корне общего репозитория. ZIP содержит одну папку `liniya-doma-furniture` со всеми исходниками и lock-файлом, без `node_modules`, `dist`, `test-results`, `playwright-report` и `.git`. Архив проверяется распаковкой, отдельными `npm ci` и `npm run build`.

Проект не зависит от файлов салона, МОТОРНОЙ или ГОРОДСКОГО ДОМА. Эти проекты и их архивы не изменены.
