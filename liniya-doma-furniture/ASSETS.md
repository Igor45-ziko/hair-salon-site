# Изображения, шрифты и графика

## Оригинальные изображения

Все мебельные интерьеры и изображения мастерской созданы специально для учебного проекта «ЛИНИЯ ДОМА» инструментом генерации изображений OpenAI 17 октября 2026 года. Это синтетические изображения вымышленной мебели и производства, а не фотографии выполненных заказов или реальной компании. Изображения с сайтов «Вереск», Guter Möbel и других компаний не использовались.

Все файлы находятся в `public/images/` и поставляются с проектом. Они преобразованы из исходного PNG в WebP с качеством 86 для быстрой загрузки. Общий объём — около 0,55 МБ. Удалённые фотосервисы, CDN и API не используются.

| Файл            | Содержание                                                                           | Использование                                     |
| --------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| `kitchen.webp`  | Светлая угловая кухня с древесными нижними и молочными верхними фасадами             | Главный экран, кухни, проект «Тёплый дуб»         |
| `projects.webp` | Четыре сцены: шкаф в спальне, гардеробная, прихожая, ТВ-зона                         | Направления и соответствующие проекты             |
| `details.webp`  | Четыре сцены: шкаф в детской, оливковая кухня, работа мастера, материалы и фурнитура | Два дополнительных проекта, мастерская, материалы |

Размер каждого файла — 1536 × 1024. Два последних файла представляют собой сетки 2 × 2. Компонент `Photo` показывает нужную четверть через CSS-позиционирование внутри контейнера с отношением сторон 3:2. `cell: 0` — сверху слева, `1` — сверху справа, `2` — снизу слева, `3` — снизу справа. Вне первого экрана применяется отложенная загрузка; главное изображение загружается с высоким приоритетом.

## Шрифт

**Golos Text Variable** подключается из npm-пакета `@fontsource-variable/golos-text` и включается Vite в локальную сборку. Кириллица поддерживается. Лицензия SIL Open Font License 1.1 находится в [public/Golos-Text-LICENSE.txt](public/Golos-Text-LICENSE.txt). Запросов к Google Fonts при работе сайта нет.

## Иконки и авторская графика

- Иконки: [Lucide](https://lucide.dev/), пакет `lucide-react`, лицензия ISC. Копия лицензии поставляется с npm-пакетом.
- Знак «ЛИНИЯ ДОМА», favicon, декоративная схема района, рисунок шкафа и линейка созданы для проекта в SVG.
- Карта декоративная: она не показывает реальное местоположение и не использует картографические сервисы. Название улицы, адрес и маршруты в этой концепции вымышлены.
- Тексты, названия проектов, палитра и композиция разработаны для этого учебного сайта. Фирменные материалы реальных мебельных компаний не копировались.
